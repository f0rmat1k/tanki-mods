# penmap — карта пробития для «Мира танков»

Мод для клиента «Мира танков» (Lesta, версия 1.46). Когда вы наводитесь на противника, рядом с прицелом появляется схема его брони. Она раскрашена под ваш текущий снаряд с учётом дистанции до цели.

| Цвет | Значение |
|---|---|
| Зелёный | пробиваете |
| Жёлтый | как повезёт (зависит от разброса пробития) |
| Красный | не пробиваете или рикошет |
| Серый | урона не будет: ствол, гусеница, экран без брони за ним |

## Что умеет

- **Расчёт.** Та же формула, что у индикатора пробития в прицеле (`gun_marker_ctrl` в скриптах игры): нормализация, рикошет, правила двух и трёх калибров, экраны, потеря пробития кумулятивом в воздухе, разброс пробития.
- **Цель и снаряд.** Берутся реальная комплектация цели (башня и орудие) и ваш текущий снаряд с пробитием на дистанции до цели. Подпись: танк, снаряд, пробитие, дистанция.
- **Виды.** Статичные: лоб и ромб 20°. В ромбе повёрнут корпус, а башня смотрит на зрителя; у машин с ограниченным горизонтальным наведением (`turretYawLimits`, ПТ с рубкой) повёрнута вся машина. Корма включается через `views`. Реальный угол, под которым стоит цель, не учитывается.
- **Цель за укрытием.** Схема показывается и для засвеченного противника за камнем или домом, если прицел задержался на его месте, а также для цели автоприцела.
- **Шпаргалка по своему танку.** Во время отсчёта мод стреляет по вашему лбу и ромбу снарядами каждого противника и показывает, какую долю брони пробивает команда противника. Рядом совет, ставить ли ромбом, и таблица: кто сколько лба пробивает обычным снарядом и голдой. С началом боя шпаргалка прячется; Ctrl+Shift+P в бою показывает её снова.
- **Окно настроек.** Ctrl+Shift+P в ангаре или ссылка в уведомлениях (колокольчик).
- **Без просадок FPS.** Броня противников распаковывается во время отсчёта. Расчёт при наведении разбит на шаги не дольше ~4 мс за кадр, а пересчёт идёт, только когда пробитие меняется больше чем на 2 %.
- **Охват.** 6–11 уровни без лёгких танков, около 970 машин. В `export.py` и `build_mod.py` это настраивается (`--min-tier`, `--skip-classes`).

## Настройки (`penmap.json`)

Все основные настройки есть в окне настроек.

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | Включить или выключить мод |
| `views` | `["front", "angle45"]` | Виды: `front` — лоб, `angle45` — ромб (имя осталось от 45°, сейчас 20°), `rear` — корма |
| `offset_x`, `offset_y` | `250`, `-120` | Положение схемы относительно центра экрана, в пикселях |
| `scale`, `side_scale` | `1.0`, `0.5` | Размер схемы; размер ромба и кормы относительно лба |
| `caption` | `true` | Подпись: танк, снаряд, пробитие, дистанция |
| `discrete` | `false` | Три чётких цвета с порогами индикатора в прицеле вместо плавного перехода |
| `show_allies` | `false` | Показывать схему и на союзниках |
| `hide_delay` | `3.0` | Сколько секунд схема висит после ухода прицела |
| `through_cover`, `cover_radius`, `cover_delay` | `true`, `3.0`, `1.0` | Схема цели за укрытием: насколько близко к её центру навестись (м) и сколько держать прицел (с) |
| `my_classes` | все классы | Показывать, только когда вы на этих классах техники |
| `only_hard`, `easy_share` | `false`, `70` | Не показывать схему, если лоб цели наверняка пробивается на `easy_share` % и больше |
| `sheet`, `sheet_distance`, `sheet_premium`, `sheet_scale` | `true`, `150`, `false`, `1.0` | Шпаргалка по своему танку: включена ли, на какой дистанции считать пробитие врагов, считать ли по голде, размер |
| `preview`, `test_vehicle`, `test_distance` | `"off"`, `"ussr:R19_IS-3"`, `200` | Тестовая схема без цели: `off`, `always` или `training` |
| `debug` | `false` | Подробный лог в `python.log` (строки `[penmap]`) |

## Как устроено

1. **Заранее, на компьютере** (Python 3, [export.py](export.py)). Скрипт читает из пакетов игры (`res/packages/*.pkg`) описания техники и коллизионные модели. Описания — упакованный XML с толщинами брони и свойствами материалов; модели — Havok 2020 (`.havok`). Танк собирается в каждой комплектации и «простреливается» лучом через каждый пиксель схемы: в лоб, ромбом и в корму. Для пикселя записывается цепочка плит с углами и расстояниями; пробитие на этом этапе не считается. Результат — один `.bin` на танк, 40–300 КБ.
2. **В бою** (Python 2.7, [mod/mod_penmap.py](mod/mod_penmap.py)). Для каждой уникальной цепочки плит мод прогоняет функции расчёта самой игры с вашим снарядом, собирает PNG с подписью и выводит его через `GUI.Simple`.

## Сборка после патча игры

Нужны Python 3 с `numpy` и `pillow`, а также Python 2.7 в `C:\Python27`. Путь к игре задан в `build_mod.py` (`GAME`). Выгрузка всех машин занимает около 20 минут.

```bash
python make_font.py
```
```bash
python export.py --out build_r20/res/mods/penmap/data --dev build_full/dev --min-tier 6 --skip-classes lightTank
```
```bash
python build_mod.py --data build_r20/res --install
```
```bash
C:\Python27\python.exe tests\run_mod_offline.py
```

## Ограничения

- **Ракурс.** Схемы статичные: лоб, ромб 20° и корма. Реальный угол цели мод не учитывает.
- **Нет A158_T832.** В файлах игры нет модели её ходовой.
- **Правила.** Мод в серой зоне: показывает справочные данные о броне, но в бою. Ставите на свою ответственность.
