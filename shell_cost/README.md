# shell_cost — серебро на снаряды в бою

Внизу экрана в бою: `На снаряды: 11 800   выстрелов: 4`. Каждый выстрел добавляет цену снаряда.

- **Цены.** Мод берёт их в ангаре: снаряды всех ваших танков, по цене покупки со скидками. Сохраняются в `mods\configs\shell_cost\prices.json`. Танк, на котором вы ещё ни разу не заходили в ангар с модом, считается после первого захода.
- **Выстрелы.** Контроллер боеприпасов игры сообщает об изменении числа снарядов. Уменьшение на N — это N выстрелов, а пополнение (например, на точках снабжения) не считается.
- **Голда.** Снаряды, которые продаются только за золото, показываются отдельно.

Настройки: `mods\configs\shell_cost\shell_cost.json` — `enabled`, `anchor` (`top` или `bottom`), `offset_x`, `offset_y`.

```bash
python build_small.py shell_cost
```
