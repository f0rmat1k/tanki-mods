# nearyou_ranks — ранги Near_You в карусели ангара

Отдельный мод для «Мира танков» (Lesta 1.46), независимый от penmap. В карусели ангара у каждого танка перед названием пишется ранг из тир-листа Near_You, а после названия — сложность игры на нём. В поиске карусели запрос с `#` фильтрует по рангу и сложности. Как пользоваться, описано в [dist_files/Установка.txt](dist_files/Установка.txt).

## Данные

Источник — `nearyou.team/setups`. Сайт на Nuxt и рендерится на сервере: в `<script id="__NUXT_DATA__">` лежит devalue-JSON со всеми машинами. У каждой есть `intCD` (идентификатор игры), `rating` (`s+ s a b c d f`) и `difficulty` (`easy medium hard hardcore`). Сопоставлять названия не нужно.

Ранги сайта совпадают с [таблицей Near_You](https://docs.google.com/spreadsheets/d/1KZiPx8zfbRb--IfR4uxYTNjsbdADxeNHTeefaMql_PA): SSS = `s+`. На 10 уровне сверено вручную. Сайт шире таблицы: все уровни, премы и сложность. Поэтому таблица не читается.

- **Загрузка.** При запуске игры `BigWorld.fetchURL`, асинхронно; разбор занимает около 20 мс. Если данные изменились, карусель перестраивается.
- **Кэш.** Последняя удачная загрузка: `mods/configs/nearyou/ratings.json`.
- **Снимок в моде.** `res/mods/nearyou/ratings.json`. Делается командой `python make_snapshot.py` и используется, пока нет кэша.
- **Защита от поломки.** Если на странице меньше 300 машин с рангом, загрузка считается сломанной, и мод оставляет старые данные.

## Как устроено

| Где | Что |
|---|---|
| `carousel_data_provider._getVehicleDataVO` | Ранг и сложность вписываются в начало `label` внутри внешнего `<font>` игры: в конце их отрезает длинное имя. `getVehicleDataVO`, который импортируют другие карусели, вызывает эту функцию по имени модуля, поэтому подпись меняется везде |
| `xvm_pymacro._container` | Макросы XVM `nearyou.label / rank / difficulty` по `{{v.sysname}}`. XVM в обычных ячейках показывает `label`, а в компактных пишет имя своим полем `{{v.name}}`, поэтому с XVM ранг выводится полем в его конфиге карусели. XVM очищает реестр при перезагрузке (`__reload`), поэтому мод регистрирует макросы снова после неё, а также при первом обращении через `process`. Если в `res_mods/configs/xvm/**/carousel*.xc` есть `nearyou.`, `label` не меняется (`label: auto`) |
| `BasicCriteriesGroup._setVehicleNameCriteria` | Текст поиска с `#` или `№` превращается в `REQ_CRITERIA.CUSTOM`. Остальное уходит в обычный поиск игры |
| `CarouselDataProvider.__init__` | Модуль запоминает карусели (`WeakSet`), чтобы обновить их после загрузки |

Новые группы галочек в окне фильтров не добавить: окно — Flash, его меняет XVM, а без Flash-инструментов туда не влезть.
