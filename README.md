# tanki-mods

Моды для клиента «Мира танков» (Lesta, 1.46) и лаунчер, который их ставит и обновляет.

| Папка | Что это |
|---|---|
| [penmap](penmap) | Карта пробития: схема брони цели, раскрашенная под ваш снаряд, и шпаргалка по своему танку перед боем |
| [nearyou_ranks](nearyou_ranks) | Ранг и сложность танка из тир-листа [Near_You](https://nearyou.team) в карусели ангара, фильтр `#` в поиске |
| [gun_marks](gun_marks) | В бою: процент отметки на стволе, урон до следующего процента и отметки, урон за бой |
| [shell_cost](shell_cost) | В бою: серебро, потраченное на снаряды |
| [camera_zoom](camera_zoom) | Отдаление камеры до 50 м |
| [auto_style](auto_style) | «Благородный мрамор» сам надевается на выбранный в ангаре танк, прежний вид возвращается танку, с которого стиль ушёл |
| [launcher](launcher) | Лаунчер: выбор модов галочками, установка и обновление из релизов этого репозитория; также обновляет XVM с официального сайта и убирает старые версии модов |

## Как поставить

Скачайте `tanki-mods-launcher.exe` из [последнего релиза лаунчера](../../releases?q=launcher), запустите, укажите папку игры, отметьте моды и нажмите «Обновить». Игра при этом должна быть закрыта.

## Как выпустить версию

penmap и nearyou_ranks собираются своими скриптами (см. README в их папках), маленькие моды — `python build_small.py <мод>`. Проверка без игры: `tests/run_small_offline.py`, тесты в папках модов. Затем:

```bash
python release.py <мод>
```

Скрипт выкладывает `.mtmod` в релиз `<мод>-v<версия>` на GitHub и обновляет [manifest.json](manifest.json), по которому лаунчер узнаёт о новых версиях.

## Правила игры

Моды меняют интерфейс клиента. Карта пробития в серой зоне правил: показывает справочные данные о броне, но в бою. Ставите на свою ответственность.
