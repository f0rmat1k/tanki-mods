# Лаунчер tanki-mods

Программа для Windows. Ставит и обновляет моды из этого репозитория.

1. Скачайте `tanki-mods-launcher.exe` из [релиза лаунчера](../../../releases?q=launcher) и запустите. Windows может предупредить, что программа неизвестна: она не подписана сертификатом. При первом запуске лаунчер предложит установиться в `%LOCALAPPDATA%\Programs\tanki-mods` и создаст на рабочем столе ярлык «Моды для Мира танков». Дальше открывайте его по ярлыку: лаунчер обновляется на том же месте.
2. Папку игры лаунчер находит сам по настройкам Lesta Game Center. Если не нашёл, нажмите «Выбрать…» и укажите папку, где лежат `paths.xml` и `Tanki.exe`.
3. Отметьте нужные моды и нажмите «Играть»: лаунчер обновит моды и запустит игру. «Обновить» делает то же самое, но без запуска. Игра при этом должна быть закрыта.

Снятые галочки удаляют мод из игры. В следующий раз достаточно открыть лаунчер и нажать «Играть»: он скачает только то, что изменилось.

Лаунчер обновляет и сам себя: если вышла новая версия, он спросит, скачает её, заменит свой файл и перезапустится. Это работает с версии 1.1.0, а 1.0.x нужно один раз заменить вручную.

## Как устроено

- **Список модов.** Лаунчер читает [manifest.json](../manifest.json) из ветки `main`. Там для каждого мода указаны версия, ссылка на `.mtmod` в релизе, размер и SHA-256. Пишет манифест [release.py](../release.py).
- **Установка.** `.mtmod` кладётся в `mods\<версия клиента>`, папку лаунчер берёт из `paths.xml`. Старые версии этого же мода (`<id>_<версия>.mtmod`) удаляются, чужие моды не трогаются.
- **Проверка.** Скачанный файл сверяется по размеру и SHA-256. До проверки он лежит как `.part`, чтобы игра не подхватила недокачанный мод.
- **Папки.** Создаются папки, которые нужны модам, например `res_mods\<версия>\mods\penmap_cache` для penmap.
- **Где что хранится.** Что установлено: `mods\configs\tanki-mods\installed.json` в папке игры. Выбор галочек и папка игры: `%APPDATA%\tanki-mods\launcher.json`.
- **Запуск игры.** «Играть» запускает `Tanki.exe` из папки игры, как это делает Lesta Game Center. Вход идёт через Game Center.
- **Установка.** Запущенный не из папки установки (`%LOCALAPPDATA%\Programs\tanki-mods`), лаунчер один раз спрашивает, скопировать ли себя туда. Затем создаёт ярлык на рабочем столе через `WScript.Shell` и перезапускается из этой папки. Отказ запоминается в `launcher.json`.
- **Сторонние моды (XVM).** В манифесте они помечены `"kind": "zip"`. Лаунчер качает официальный архив с сайта автора, у XVM это `nightly.modxvm.com` (ссылка со страницы загрузки modxvm.com), сверяет SHA-256 и распаковывает папку `lesta/` в игру. Номер клиента в путях `mods/<версия>` и `res_mods/<версия>` подставляется текущий. Установленную версию лаунчер узнаёт по файлу `com.modxvm.xvm_<версия>.mtmod`. Свой `xvm.xc` и другие свои конфиги не перезаписываются (в архиве только `default`, `py_macro` и `xvm.xc.sample`). Старые версии пакетов из архива убираются. Снятая галочка сторонний мод не удаляет, а только перестаёт обновлять. Новую версию XVM в список добавляет `python release.py xvm --url <ссылка на архив>`.
- **Старые версии модов.** С галочкой «Убирать старые версии модов» лаунчер находит `.mtmod` одного пакета разных версий (`<id>_<версия>.mtmod`, в том числе в подпапках вроде `net.openwg`) и оставляет только новую. Старые переносятся в `mods\configs	anki-mods\old_versions\<дата>`, их можно вернуть.
- **Самообновление.** Запущенный `.exe` нельзя перезаписать, но можно переименовать. Поэтому лаунчер скачивает новую версию, сверяет её SHA-256, переименовывает себя в `.old`, кладёт новую на своё место и перезапускается, а `.old` удаляет при следующем старте. Для проверки собранного `.exe` без окна-вопроса есть переменная окружения `TANKI_MODS_LAUNCHER_YES=1`.

## Сборка

```bash
python -m pip install pyinstaller
```
```bash
python launcher/build.py
```

Сборка кладёт `.exe` в `launcher/dist/<версия>/`: открытый лаунчер держит свой файл, и новая сборка его не перезаписывает.

```bash
python launcher/test_launcher.py
```
```bash
python release.py launcher
```
